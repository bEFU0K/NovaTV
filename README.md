# Nova TV OS (лаунчер для Android TV)

Kotlin + Jetpack Compose, minSdk 24 (Android 7+). Фон — ваша картинка (`res/drawable-nodpi/bg_nova.png`).

## Что внутри
- Вход ТОЛЬКО по QR (через сайт Srepportal), без пароля на ТВ. Без входа доступны лишь «Интернет» и «Bluetooth».
- Файловый менеджер (память, USB), установка APK/XAPK/APKS/APKM, открыть XAPK в TAPK.
- Настройки: интернет, Bluetooth, громкость, экранная клавиатура RU/EN, фон, акцент, VPN-статус.
- **TAPK.apk вшит** в приложение (`assets/tapk.apk`) и ставится при первой настройке.
- Остальные приложения (Кинопоиск, PREMIER, Яндекс Музыка, YouTube, Яндекс Браузер, Peers.TV, Happ) **скачиваются с вашего сайта** при первой настройке (SHA-256 проверяется), удаление блокируется (см. «Защита»).

## Сборка без установки программ (GitHub)
1. Зарегистрируйтесь на github.com → New repository (Private) → Create.
2. «uploading an existing file» → перетащите ВСЁ содержимое папки NovaTV (включая скрытую `.github`) → Commit.
3. Вкладка Actions → «Build Nova TV» → Run workflow (≈5–10 мин).
4. Откройте завершённый запуск → внизу Artifacts → `NovaTV-debug-apk` → скачайте, распакуйте → `app-debug.apk`.
Если сборка красная — откройте шаг с ошибкой и пришлите текст: код ещё ни разу не собирался.

## Установка на ТВ
1. Загрузите серверный zip на сайт (инструкция внутри `srepportal-tv-server.zip`).
2. На ТВ: включите «Режим разработчика» → «Отладка по USB/сети» (Настройки → Об устройстве → 7 раз на «Сборка»).
3. На ПК: `adb connect IP_ТВ:5555` → `adb install -r app-debug.apk` (или с флешки через файловый менеджер).
4. Настройки ТВ → Приложения → Домашний экран → Nova TV OS.
5. Следуйте шагам на экране: сеть → QR-вход → установка приложений (подтверждайте окна Android).

## Защита от удаления (по-настоящему)
Один раз выполните на ПК (на ТВ не должно быть добавленных аккаунтов Google):
`adb shell dpm set-device-owner com.srep.novatv/.AdminReceiver`
Тогда Android сам блокирует удаление Nova, TAPK и скачанных приложений, а установка идёт без лишних окон.
Без этой команды защита «мягкая»: кнопки удаления скрыты, а удалённое приложение предлагается скачать заново.

## Ограничения (честно)
- Это лаунчер, а не системный образ. Перепрошить ОС (recovery/OTA) приложением нельзя.
- Wi-Fi подключается через системное окно Android (без системных прав приложение не может само).
- Несовместимые с ТВ приложения пропускаются (Яндекс Музыка нужен Android 12+, PREMIER и Peers.TV — 64-бит ARM).
- Код не компилировался в среде разработки (нет сети/Gradle).
