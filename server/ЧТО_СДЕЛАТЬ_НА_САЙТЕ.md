# Что поменять на srepportal.craft-host.ru

Nova TV берёт приложения с сайта: список — `/api/tv/apps.php`, сам файл — `/api/tv/get.php?id=...`.
Серверного zip в этом чате не было, поэтому эти два файла я не переписывал — внесите правки в ваши.

## 1. Загрузить 5 файлов из rar (переименовать!)
Положите их туда же, где у вас лежат файлы для `get.php` (папка приложений ТВ), под такими именами:

| Исходное имя в rar | Имя на сайте | id | пакет |
|---|---|---|---|
| Yandex+Music,+Books+&+Podcasts_2025.05.4+#99.1rur_APKPure.apk | `yandex-music.apk` | `yandex-music` | `ru.yandex.music` |
| YouTube+for+Android+TV_5.30.320_APKPure.xapk | `youtube.xapk` | `youtube` | `com.google.android.youtube.tv` |
| PREMIER+-+Сериалы,+фильмы,+шоу_2.107.0-googletv_APKPure.xapk | `premier.xapk` | `premier` | `gpm.tnt_premier` |
| Happ.apk | `happ.apk` | `happ` | `su.happ.proxyutility` |
| Яндекс+Браузер+для+ТВ_26.8.1.703_APKPure.xapk | `yandex-browser.xapk` | `yandex-browser` | `com.yandex.browser.tv` |

## 2. `api/tv/apps.php` — список приложений
Добавьте эти 5 записей в список (готовый JSON — в `apps.json`; `size` и `sha256` уже посчитаны по вашим файлам, их нельзя менять, если файл заменён — пересчитайте: `sha256sum файл`).
Формат ответа: `{"apps":[{id, name, pkg, ext, size, sha256, min_sdk, abis}, ...]}`.
- Если раньше был «Happ» с пакетом `com.happproxy` — замените на `su.happ.proxyutility` (в файле из rar пакет именно такой).

## 3. `api/tv/get.php` — отдача файла
- Файлы большие (до 67 МБ): отдавайте потоком (`fread` кусками по 128 КБ в цикле), не через `file_get_contents`.
- Обязательно поддерживайте заголовок `Range` (ответ 206 + `Content-Range`) — ТВ докачивает файл после обрыва.
- Заголовок `Content-Length` = точный размер файла.
- Проверка токена (`Authorization: Bearer` / `X-Nova-Token`) остаётся как есть.

## 4. Хостинг
Проверьте на craft-host: лимит загрузки файла (нужно ≥ 70 МБ) и `max_execution_time` у `get.php` (отдача 67 МБ по медленному каналу).

## 5. Чтобы всё сохранялось при обновлении
Серверные файлы трогать не нужно. Новые приложения, добавленные в `apps.php`, ТВ сам подхватит при следующем запуске Nova и предложит установить.
